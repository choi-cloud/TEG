## 6. 이상 징후
1. 덤프 텐서(관점 L 점수 ℓ^L)는 원시 logit이 아니라 `softmax(−dist)` 확률(값 범위 [0, 1])이다. 지시서 정의대로 관점 L 확률 = softmax(ℓ^L / T_L)를 이 확률 텐서에 적용했다. 선택된 T_L은 18 run 모두 10^−0.8(0.158)·10^−0.6(0.251) 중 하나다.
2. 격자 끝 최적값: 없음(T_L, s 모두 격자 내부).
3. 표 B "나은 끝점"(seed 평균 test 정확도 기준)은 dblp 1-shot만 TEG(α = 1)이고 나머지 5개는 D(α = 0)다.
4. 표 A의 max·argmax α는 seed 평균 곡선에서 계산했다. argmax 동률이면 1에 가까운 값으로 정했다(지시서 미기재 — 표 B 동률 규칙과 같은 방향).
5. 표 C 동률 규칙: α_val에 가장 가까운 A5 값, 그래도 동률이면 큰 α. 고정 조건은 α_val 자체(A5 밖 값일 수 있음)로 평가했다.
6. 관점 D 프로토타입은 행 정규화 h̄의 support 평균이다(지시서 §3.1). G3 α = 0 대조에서는 `probe_acc`에 h̄를 넣었다. T06b가 `probe_acc`에 넣은 공간은 정규화 전 Â²X였으므로, 5-shot에서는 T06b 표의 `diff2` 값과 프로토타입 정의가 다르다.
7. NLL은 대상 에피소드 50개의 모든 query(1,250개)에 대한 평균이다. 에피소드마다 query 수가 같아 에피소드 평균의 평균과 같다.
8. 표 D 비율은 run마다 test query 1,250개로 계산한 뒤 seed 평균 ± sd로 적었다.
9. `eval_logits.npz`는 에폭 0을 포함한 11 에폭 × (valid 50 + test 50) = 1,100 에피소드를 담는다. `classes`는 float로 저장된다(원 라벨 값 형식).
