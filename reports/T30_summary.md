# T30 요약 — 클래스별 분해 (학습 없음), T22 고정 test 에피소드

- 에피소드: T22 `base` `fixed_eval_logits.npz` mode 1 (seed당 200, `Random(9000 + seed)`), `ep_idx` 순, seed 0–9.
- arm: X0 / D = `fusion_baseline.view_d_scores` argmax (행 L2 X / Â²X 코사인 프로토타입), TEG / C_all = `logits` argmax (`base` / 선택 λ `infonce_all`: Amazon_clothing 1-shot 10, Amazon_clothing 5-shot 10, dblp 1-shot 10, dblp 5-shot 10, Amazon_electronics 1-shot 100, Amazon_electronics 5-shot 30).
- 클래스별 정확도: 그 클래스가 포함된 에피소드마다 그 클래스 query 5개의 정확도. 짝지은 차는 같은 에피소드끼리, 분명 = 평균 > 0이고 > 2·SE (음수는 부호 반대).
- e_c: D 공간, 분할은 `results/T29/splits.json` (seed별), base 클래스 평균 중심화 행렬의 SVD 오른쪽 특이벡터(특이값 > s_max·max(shape)·eps). r_c: X0 공간, δ 상위 50열의 base 노드 비영 비율 평균. 둘 다 seed 평균.
- 3분위: 값 ≤ `np.quantile(·, 1/3)`인 클래스를 하위 3분위로 둔다. Spearman: `scipy.stats.spearmanr`, 단위 = 그 칸의 test 클래스 전체.
- 클래스별 전체 표: `reports/T30_per_class.md`.
