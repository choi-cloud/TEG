- **z 텐서**: 학습 에피소드 forward의 전체 노드 GCN 출력 `embeddings = self.conv(self.features, self.edges)`(`model.py:325`)를 그대로 받는다. `pres_loss` 안에서 `z = F.normalize(self.egnn.LayerNorm(embeddings[idx]), dim=1)`(`model.py:179`)로 쓴다. `self.egnn.LayerNorm`은 EGNN이 좌표 입력에 적용하는 그 모듈이다(`layers/EGNN.py:70`, `coord_feature = self.LayerNorm(coord_feature)`). LayerNorm은 행 단위라 전체 노드에 적용한 뒤 인덱싱한 값과 같다. GCN 추가 forward 없음.
- **λ = 0 경로**: `__init__`의 교사·풀·생성기 생성과 `train_epoch`의 손실 계산·샘플링은 모두 `if ... pres_lambda > 0` 블록 안에 있다. λ = 0이면 실행되지 않는다.
- **G1 난수**: `git diff` 추가 줄의 난수 관련 호출은 세 가지다.
  - `torch.Generator().manual_seed(7000 + seed)`(전용 생성기 생성)
  - `torch.randperm(..., generator=self.pres_gen)`
  - `random.Random(9000/9100 + seed)` 전용 인스턴스(고정 에피소드)
  - 전역 `random`·`np.random`·`torch` 기본 생성기 호출은 없다.
- **고정 평가 forward**: eval 모드(`conv.eval()`, `egnn.eval()`)·`no_grad`. GCN의 `F.dropout(training=False)`는 난수를 쓰지 않고, EGNN에는 난수 호출이 없다.

## 6. 이상 징후
1. G2 체크포인트 재평가 2 run 불일치(3절). 두 run 모두 valid 동점이고, `ckpt_epoch` ≠ `best_epoch_valid`다.
2. `pres_loss_mean`은 에폭 0에도 기록된다. 에폭 0 학습 루프는 원본에서 갱신(backward)을 하지 않는다. 보존 손실도 에폭 0에는 계산·기록만 하고 갱신에는 쓰이지 않는다(원본 분기 그대로).
3. 보존 손실 풀 `nb`는 라벨이 `class_list_train`(seed별 valid 분할 이후의 base 클래스)에 없는 노드 전체다. valid·test 클래스 노드가 포함된다.
4. 전용 생성기 시드는 `7000 + set_seed`(= `--seed`, `--num_seed 1`)이다. 고정 에피소드는 `random.Random(9000 + seed)`(test 200)·`random.Random(9100 + seed)`(valid 100)이다. 에피소드 노드 추출 순서는 `task_generator_in_class`와 같다(클래스마다 `rng.sample(·, K + Q)` → 앞 K개 support).
5. 고정 평가의 `ep_idx`는 test 0–199, valid 0–99이다(`epoch` = −1).
6. 설정 선택(sel)은 6셀 모두 `nb` 풀이다(l1_nb 3, l10_nb 3).
7. F(cfg) 온도 보정의 격자 끝 최적값: 0개 run.
8. `base` 설정의 고정 test 정확도와 원본 `test_acc_at_best_valid`는 서로 다른 에피소드 집합(고정 200 vs 원본 50)에서 나온 값이다(표 1).
9. G4 점검은 `git show t08b:tools/fusion_baseline.py`를 임시 파일로 꺼내 import해 비교한 뒤 삭제했다.
