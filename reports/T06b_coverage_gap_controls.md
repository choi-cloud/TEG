## 6. 이상 징후
1. G3 ρ̄_A 항목 실패(3절). 분산 가중 잔차는 전부 0.10 미만이고, 지시서 정의(비순서쌍 잔차 비율의 비가중 평균)는 0.12를 넘는 행이 4개다.
2. 표 B1의 `raw`·`diff2` 열이 T06 표 B1의 `raw`·`diff` 열과 모든 셀에서 같다. 같은 split·같은 probe 난수(`random.Random(1000 + seed)`)·같은 공간이다.
3. 표 C의 판정은 24행 모두 "불통과", 표 C-s(0.80 / 0.90 / 0.95 / r = 10)도 96칸 모두 "불통과"다.
4. 자율 판단 내역:
   - PCA(`pca1`, `pca2`)는 sklearn `PCA(n_components=64, svd_solver="randomized", random_state=0)`으로 데이터셋마다 한 번 적합했다. 지시서 분석 난수 목록에 PCA 항목이 없다.
   - `rand*`의 R은 `np.random.default_rng(2000 + seed).normal(0, 1/8)`이고, (데이터셋, seed)마다 한 번 만들어 `rand1`·`rand2`에 공유했다.
   - 검사 ②의 base 반분할 20개는 seed마다 한 번 만들어 모든 공간 행에 공유했다. A = `rng.sample(base, ⌊|base|/2⌋)`이라 Amazon_electronics(base 91)는 A 45 / B 46이다.
   - 순열용 `np.random.default_rng(4000 + seed)`는 (행, seed)마다 새로 만들었다. 분할마다 순열 1,000개를 뽑아 네 가지 규칙(0.80/0.90/0.95/r = 10)에 공유했다.
   - 주성분은 순서쌍 차이 대신 중심화한 프로토타입의 SVD로 계산했다. 같은 주축·같은 분산 비율이고, 독립 구현과 r 일치를 확인했다(3절).
   - principal angle은 두 기저의 곱 `B_A B_X^T`의 특이값 평균이다. P_T는 test 클래스 프로토타입으로 같은 0.90 규칙을 써서 seed마다 하나 만들었다.
   - `test_eps.npz`의 E = (epochs + 1) × 50 = 550이다(에폭 0 포함).
   - 표 D의 정확도 셀은 seed별 50 에피소드 평균의 seed 평균 ± sd다. 차는 150개 에피소드 짝지은 차의 평균 ± SE다.
5. `GCN2` 생성 시 GCNConv 두 층의 가중치 초기화는 torch 기본 초기화(전역 torch 난수)를 쓴다. L2는 별도 모델 변형이고, 새로 작성한 코드에서 난수 함수를 직접 호출하지 않는다.
6. L1 `test_acc_at_best_valid`가 T06과 다른 run이 3/18이다(G1 참고 표).
