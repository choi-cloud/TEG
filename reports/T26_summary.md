# T26 요약 — ogbn-arxiv(입력 128차원)에서 D vs GPN

- S0 = 행 L2 정규화(adj²X), adj = `utils.load_data("ogbn-arxiv")`의 행 정규화 D⁻¹(A+I)(원 엣지 방향, GPN이 받는 연산자). S0_sym(기록) = A ∪ Aᵀ(중복 제거) + I의 대칭 정규화 D^-1/2 (A+I) D^-1/2로 2-hop 전파 후 행 L2 정규화(`analyze_t26.s0_sym`). P16(기록) = S0의 PCA 16차원(`random_state=18500`). G = GPN best-valid 임베딩(16차원, probe shot과 같은 shot의 run). seed 0–2.
- probe: `analyze_t06b.episodes` + `fewshot_acc`(코사인 프로토타입, 500 에피소드, `random.Random(1000 + seed)`, 그룹 base → valid → test 순). 클래스 분할 = `dataset/ogbn_arxiv/cls_split.pkl`(seed와 무관). 정확도 %.
- 출력 수준: D = S0 위 support 평균 + 코사인, D_sym = S0_sym 위 같은 규칙, GPN 출력 = `ckpt_best.pt`(eval) + 업스트림 `test()` 수식(degree 0 노드는 학습과 같이 degree 1).
