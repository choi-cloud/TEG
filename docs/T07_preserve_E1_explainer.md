## 0. 한 줄 요약

TEG 학습에 "레이블 없는 노드들 사이의 이웃 관계를 확산 특징(Â²X)에서와 같게 유지하라"는 손실 하나를 더했더니, **test 정확도가 6개 조건 모두에서 +2.0–7.7%p 올랐고**, 학습된 임베딩이 안 본 클래스를 구분하는 능력이 학습 없는 확산 특징보다도 높아졌다. 학습 없는 "TEG + 확산 특징 결합" 기준선과는 대체로 비기거나 앞서며(Amazon 1-shot에서 분명히 앞섬), 이 모델에 다시 결합을 얹으면 Amazon 4개 조건에서 가장 좋은 성능이 나온다.

---

## 1. 배경 — 왜 이 실험을 했나

앞선 진단 실험(T06, T06b, T08)에서 다음 네 가지를 확인했다. 모두 TEG 원본(1층 GCN 64-d + EGNN), 3 데이터셋(Amazon_clothing, dblp, Amazon_electronics) × 5-way 1/5-shot × seed 3 기준이다.

1. **학습 없는 방법이 TEG와 같거나 낫다.** 확산 특징 Â²X(Â는 self-loop를 더한 대칭 정규화 인접행렬)를 그대로 쓰고, support 평균을 프로토타입으로 해 코사인 최근접으로 분류하면, TEG가 실제로 푼 test 에피소드에서 6개 조건 중 5개에서 TEG와 같거나 높았다. TEG가 이긴 것은 dblp 1-shot뿐이다.
2. **학습은 "본 클래스"만 잘 가르게 만든다.** GCN 인코더 학습은 base(학습) 클래스 구분력을 크게 올리지만, 학습에 쓰이지 않은 클래스(valid, test) 구분력은 훨씬 덜 올리거나 오히려 떨어뜨린다. valid 클래스도 test와 똑같이 손해를 본다. 즉 문제는 "base 대 novel의 분포 차이"가 아니라 **"본 클래스 대 안 본 클래스"**다.
3. **안 본 클래스는 "새 축"이 아니라 "낮은 해상도"의 문제다.** novel 클래스를 가르는 데 base가 쓰지 않는 고유한 방향이 필요하다는 증거는 없었다. 대신 학습된 임베딩에서 안 본 클래스들의 차이는 몇 개의 공용 방향에 눌려 있었다. 입력(확산 특징)에는 이들을 가를 정보가 있는데, base로만 학습한 인코더가 그 정보를 보존할 이유가 없어 접어 버린 것으로 본다.
4. **두 관점을 섞으면 각각보다 낫다.** TEG의 예측 확률과 확산 특징 코사인 예측을 온도 보정 후 반반(α = 0.5)으로 섞으면, 학습 없이 TEG보다 +1.9–6.8%p 높다(T08b). 이후 모든 방법이 넘어야 할 기준선으로 채택했다.

이로부터 처방이 나온다. **인코더가 base를 배우는 동안에도, 확산 특징이 가진 "누가 누구와 가까운가"를 버리지 못하게 하자.** 이것이 이 실험의 보존 손실(Preserve)이다.

## 2. 실험 질문

- **Q0.** TEG에 보존 손실을 더하면 TEG보다 나은가?
- **Q1.** 그 모델이 학습 없는 결합 기준선(TEG + 확산, α = 0.5)보다 나은가?
- **Q2.** 보존한 모델에 다시 확산 결합을 얹으면, 원본 TEG + 결합보다 나은가?
- **보조.** 보존 손실이 실제로 "안 본 클래스의 표현 해상도"를 되돌리는가? 어느 노드를 보존해야 하는가?

## 3. 방법 — 보존 손실

### 3.1 무엇을 더했나

TEG의 학습 손실(γ·L_N + (1−γ)·L_G)에 항 하나를 더한다.

  **L = L_TEG + λ · L_pres**

- **교사**: 학습 전 한 번 계산하는 확산 특징 h̄ = 행 정규화 Â²X. 학습되지 않는다.
- **학생**: 학습 중인 표현 z. TEG에서 EGNN이 받는 노드 좌표 입력(GCN 출력에 EGNN의 LayerNorm을 적용한 것)을 쓴다. 학습 step마다 이미 계산된 전체 노드 GCN 출력을 재사용하므로 추가 forward는 없다.
- **손실**: 학습 step마다 노드 풀 U에서 m = 1,024개를 뽑아, 각 노드 i에 대해 "다른 노드들 중 누가 가까운가"의 분포를 교사와 학생에서 각각 만들고 KL로 맞춘다.
  - p^T_i = softmax_{j≠i}( cos(h̄_i, h̄_j) / τ ), p^S_i = softmax_{j≠i}( cos(z_i, z_j) / τ ), τ = 0.1
  - L_pres = 평균_i KL(p^T_i ‖ p^S_i). 교사 쪽으로는 gradient가 흐르지 않는다.
- **추론은 TEG 원본과 같다.** 보존 손실은 학습에만 쓰인다.

### 3.2 장난감 예시

교사 공간에서 노드 i의 가까운 이웃이 j(유사도 0.9), k(0.8)이고 l은 멀다(0.1)고 하자. base로만 학습하면 j와 k가 공용 방향에 눌려 i와 모두 0.95처럼 붙을 수 있다. j와 k가 서로 다른 안 본 클래스라면 이 구분이 사라진다. L_pres는 "i에게 j가 k보다 가깝다"는 순서와 간격을 되살리도록 z를 당긴다. τ가 작아서 먼 노드 l과의 관계는 거의 무시하고, **가까운 이웃 사이의 미세한 차이**에 집중한다. 해상도 손실이 일어나는 곳이 바로 거기다.

### 3.3 노드 풀 U

- `nb`: base 클래스에 속하지 않는 노드 전체(= valid·test 클래스 노드). 레이블은 쓰지 않고 "base가 아니다"는 사실만 쓴다.
- `all`: 전체 노드. 영역 정보를 전혀 쓰지 않는 버전.

## 4. 실험 설정

| 항목 | 내용 |
|---|---|
| 모델 | TEG 원본(하이퍼파라미터·optimizer·에폭 수 그대로) + 보존 손실 |
| 설정 7개 | `base`(λ = 0, TEG 원본) / λ ∈ {0.1, 1, 10} × U ∈ {nb, all}. τ = 0.1, m = 1,024 고정 |
| 데이터 | Amazon_clothing, dblp, Amazon_electronics × 5-way {1, 5}-shot × seed {0, 1, 2} → 설정당 18 run, 총 126 run |
| 모델 선택 | TEG 원본 규칙(valid 정확도 최고 에폭) |
| 설정 선택 | (데이터셋, shot)마다 λ > 0인 6개 설정 중 valid 정확도(seed 평균)가 가장 높은 것 = `sel` |
| 평가 | **고정 test 에피소드**: seed마다 전용 난수로 test 클래스에서 뽑은 200개(5-way, K-shot, 클래스당 query 5개). 7개 설정 모두 같은 에피소드에서 평가 |
| 비교 방식 | 같은 에피소드끼리 짝지은 차이. 600개(200 × seed 3)의 평균 ± SE, seed 부호 일치 수 |

**고정 에피소드를 쓴 이유.** TEG는 에폭마다 test 에피소드를 새로 뽑고, 설정마다 고른 체크포인트(에폭)가 다르다. 원래 기록으로 비교하면 설정마다 서로 다른 test 문제를 푼 셈이 된다. 그래서 학습이 끝난 뒤 각 설정의 체크포인트를 같은 고정 에피소드에서 다시 평가했다.

**비교 기준선.**

| 이름 | 정의 | 학습 |
|---|---|---|
| TEG | `base` 설정 | 있음 |
| D | Â²X 행 정규화 코사인 프로토타입 | 없음 |
| F(base) | TEG 예측 + D, 온도 보정(고정 valid 에피소드 100개) 후 α = 0.5 결합 | TEG 외 없음 |
| F(sel) | 보존 모델 예측 + D, 같은 방식 결합 | — |

**확인한 안전장치.**
- 보존 손실의 노드 샘플링은 전용 난수 생성기만 썼다. 같은 seed에서 7개 설정이 뽑은 학습·평가 에피소드가 전 에폭에서 완전히 같음을 확인했다. 즉 보존 손실이 TEG의 원래 난수 흐름을 바꾸지 않았다.
- λ = 0이면 보존 관련 코드가 전혀 실행되지 않는다.

## 6. 해석

1. **보존 손실은 TEG의 약점을 직접 고친다.** 이득은 TEG가 학습 없는 방법에 가장 크게 뒤지던 조건(Amazon 1-shot)에서 가장 크다(+6.9, +7.7%p). 그리고 5.3의 표현 진단에서 이득의 원인이 확인된다. 안 본 클래스의 표현 해상도가 회복됐다. 진단(1절의 2·3) → 처방(보존 손실) → 메커니즘 확인(5.3)이 한 줄로 이어진다.
2. **학습 없는 결합 기준선과는 "같거나 낫다".** Amazon 1-shot 두 조건에서는 분명히 앞서고, 나머지는 비긴다. 결합 기준선은 시험 때 확산 특징을 따로 계산해 섞어야 하는 반면, 보존 모델은 TEG와 같은 추론 경로의 단일 모델이다.
3. **보존과 결합은 Amazon에서 서로 보완한다.** 보존 모델에 결합을 얹으면 Amazon 4개 조건에서 더 오른다. Clothing 1-shot은 TEG 80.7 → 89.1이다. 보존이 확산 구조를 완전히 흡수하지는 못했고, 남은 부분을 결합이 채운다고 볼 수 있다.
4. **dblp는 다르게 행동한다.** dblp에서는 확산 특징 자체가 약하다(D 73.1, TEG보다 낮음). 보존은 여전히 TEG를 +2%p 올리지만, 보존 모델에 결합을 다시 얹으면 이득이 없거나 조금 떨어진다. 교사가 약한 데이터셋에서는 확산 구조를 한 번 반영하는 것으로 충분하다는 뜻으로 읽는다.
5. **영역 정보가 필요 없다.** 전체 노드를 보존해도 결과가 거의 같다. "레이블 없는 test 영역을 안다"는 transductive 가정에 기대지 않는다.

## 7. 한계와 주의

- **seed 3개, 데이터셋 3개, 백본 TEG 하나.** 다른 GFSL 모델(예: GCN + ProtoNet)에서도 같은 효과가 나는지는 아직 모른다.
- **자기지도 보조 손실과의 비교가 없다.** 보존 손실은 넓게 보면 "레이블 없는 노드에 대한 보조 손실"이다. 대조 학습(GRACE류) 같은 일반적인 보조 손실보다 나은지, 즉 "확산 이웃 구조를 교사로 쓰는 것"이 핵심인지를 아직 보이지 않았다.
- **설정 선택에 valid를 썼다.** 선택된 설정이 test 최적과 다른 경우가 있다(dblp 1-shot: 선택 λ = 10은 77.6, λ = 1은 78.5). 선택 잡음 수준이다.
- **게이트 기록 1건.** 126 run 중 2 run에서 체크포인트 재평가가 어긋났다. 원인은 valid 정확도 동점이다. TEG 원본 코드는 test 정확도를 나중 에폭으로, `best_epoch_valid`를 먼저 에폭으로 기록하는데, 게이트 정의가 후자를 기준으로 삼았다. 체크포인트 자체는 원본 test 정확도를 낸 에폭과 같고, 두 run은 5.1·5.2의 선택 설정에 포함되지 않는다. 기준 정정 후 태그 `t07`을 부여하는 절차를 진행 중이다.
- **고정 에피소드 정확도는 TEG 원본 보고 방식(best 에폭의 test 에피소드 50개)과 에피소드 집합이 다르다.** 두 숫자를 직접 섞어 비교하지 않는다.

## 8. 다음 단계 (제안)

1. **자기지도 보조 손실 기준선 추가.** 같은 자리에 대조 학습 손실을 넣어 비교한다. 이 스토리의 차별점이 걸린 비교다.
2. **백본 일반성.** 다른 GFSL 모델 하나 이상에 같은 손실을 붙인다.
3. **Rehearse(가짜 클래스 에피소드)의 필요성 재검토.** 보존만으로 이득이 크므로, Rehearse는 2×2 실험으로 추가 기여가 있는지만 확인한다.
