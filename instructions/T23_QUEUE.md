## 0. 무엇을 묻는가

새 스토리 후보(다중 해상도 에피소드 구성)의 전제는 하나다.

> **학습 없는 입력(X, ÂX)으로 만든 다중 해상도 클러스터가, 임베딩 거리에 없는 같은-클래스 정보를 담고 있다.**

이 큐는 그 전제를 학습 없이 세 단계로 잰다.

| 지시서 | 질문 | 산출 |
|---|---|---|

모든 레이블은 지표 계산에만 쓴다. 클러스터링은 전체 노드에 대해 한다(CLAUDE.md §3, 2026-10-14 결정). **학습 실행은 없다.**

## 1. 진행 규칙 (이 큐에 한해 CLAUDE.md §2를 다음처럼 적용)

1. 순서: T23a → T23b → T23c. 각 지시서가 끝나면 보고서 커밋 + 태그까지 하고, **멈추지 않고 다음 지시서로 넘어간다.** 다음 지시를 기다리는 멈춤은 큐 끝에서 한 번만 한다.
2. 코드 작성 전 멈춤(§2 멈춤 1)은 면제한다. 대신 각 보고서 1절에 파일 단위 계획(함수 목록, 재사용한 기존 구현의 `파일:줄`)을 적는다.
3. **게이트 실패는 멈춤이다.** 실패한 지시서의 보고서를 쓰고(태그 없음), 커밋·push한 뒤 큐를 멈추고 보고한다. "기록" 표시가 있는 게이트는 멈추지 않는다.
4. 수치 동작에 관한 판단이 지시서에 없으면, auto mode에서는 멈추지 않고 가장 단순한 쪽을 택해 "이상 징후"에 적는다(§2의 "멈추고 묻는다"를 이 큐에 한해 완화). 단 레이블 사용 범위와 §7은 예외 없이 지킨다.
5. 코드는 새 파일 하나 `tools/t23.py`(하위 명령 방식)에 둔다. 학습 코드(`main.py`, `model.py`, `utils.py`, `argument.py`, `embedder.py`, `layers/`)와 기존 `tools/*.py`는 고치지 않고 import만 한다.

## 2. 시간 예산 (착수 시각 T0 기준)

| 구간 | 예산 | 넘으면 |
|---|---|---|
| T23a | T0 + 20분 | 그대로 진행. 아래 마감만 지킨다 |
| T23b | T0 + 38분 | 그대로 진행 |
| T23c | T0 + 55분 | 우선순위 낮은 것부터 뺀다(T23c §8) |
| 마감 | **T0 + 60분** | 진행 중인 계산을 끊고, 끝난 부분만으로 보고서를 쓴 뒤 커밋·push한다. 빠진 표는 "미실행(시간)"으로 적는다 |

- 각 보고서에 실행 시간(분)을 적는다.
- 계산은 GPU 여러 장에 나눠 돌린다(CLAUDE.md §4: 3번 제외, UUID 지정, 동시 6개 이하). 분석 프로세스 하나에 GPU 하나.
