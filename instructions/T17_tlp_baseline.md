# T17 — TLP식 기준선: 지도 손실 없이 대조 학습만 한 인코더

2026-10-09 · 작성: 채팅 Claude · 모드: auto(overnight 큐) · 브랜치 `erasure_diagnosis` · 태그 `t17` · 선행: `t16a`(게이트 전부 통과). T16b와는 독립이다.

## 0. 목적과 검증 가능한 주장

**주장**: 같은 1층 64차원 GCN을 지도 손실 없이 GRACE식 대조 학습만으로 학습한 인코더를 TLP 방식(코사인 프로토타입, 로지스틱 회귀 probe)으로 평가한 정확도와, 원본·대조·대조+D의 정확도를 **같은 고정 test 에피소드**에서 짝지어 비교한 값을 산출한다.

## 1. 설정

| # | 설정 | 플래그 | run |
|---|---|---|---|
| G1(λ) | 대조만 | `--sup_coef 0`, 대조 인자는 T14 `uni`와 같고 λ ∈ {1, 10, 100}. `--fixed_eval --traj_every 50 --traj_lr 1` | 3 λ × 3 데이터셋 × {1, 5}-shot × seed 0–4 = 90 |
| G2 | 대조만, 2층 GCN | G1의 선택 λ*, `--gcn_layers 2` | 30 |

**G2 사전 점검**: Clothing 1-shot seed 0 한 run이 오류 없이 끝나는지 먼저 확인한다. 실패하면 G2는 건너뛰고 이상 징후에 적는다. 이 지시서의 실패로 보지 않는다.

**선택 규칙** (test는 선택에 쓰지 않는다)
- 측정점 선택: run마다 측정점(step 0, 50, …, 500) 중 `cos_valid`(M5)가 최고인 지점을 고른다. 동점이면 앞 지점이다. 그 지점의 `cos_test`, `lr_test`를 보고한다.
- λ* 선택: (데이터셋, shot)마다 선택 지점 `cos_valid`의 seed 평균이 최고인 λ다. 동점이면 작은 λ다.

**기존 결과 재사용(재실행 없음)**: T14의 `base`(= 원본)와 `uni`(= 대조), seed 0–4.
- 고정 test TEG 정확도
- F(대조)(T14 +D 결합)
- T14 `emb_best.npy`(원본, 대조)에 대해, 같은 고정 test 에피소드에서 코사인 프로토타입과 로지스틱 회귀 정확도를 오프라인으로 계산한다. `tools/erasure_metrics.py`를 쓴다.

## 2. 비교 (고정 test 에피소드 짝지은 차, (데이터셋, shot)마다 1,000 에피소드)
