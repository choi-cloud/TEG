## T09 — 보존 손실 성분 분해 + 자기지도 기준선 (보고 `reports/T09_preserve_ablation.md`, 요약 `reports/T09_summary.md`, 태그 `t09`)

### 목표
보존 손실의 이득이 (a) 확산 이웃 구조라는 **교사**에서 오는지, (b) 이웃 분포 KL이라는 **손실 형태**에서 오는지, (c) 단순히 "레이블 없는 노드에 보조 손실을 건다"는 데서 오는지(일반 자기지도 대조 학습과 비교) 가른다.

### 코드
- `--pres_teacher_hops` (int, 기본 2): 교사 = 행 정규화 Â^k X, k ∈ {0, 1, 2}(k = 0은 X).
- `--pres_loss` (`kl` | `mse` | `infonce`, 기본 `kl`):
  - `kl`: T07과 동일.
  - `mse`: 표본 B에서 평균_{i≠j} (cos(z_i, z_j) − cos(h̄_i, h̄_j))².
  - `infonce`: 교사 없음. GRACE식 두 뷰 대조 손실. 뷰마다 특징 마스킹(열 단위, p = 0.3)·간선 제거(p = 0.2)를 전용 생성기(시드 `8000 + seed`)로 만들고, GCN을 뷰마다 한 번씩 추가 forward(`fork_rng` 안, 학습 모드). 표현 = EGNN LayerNorm 적용 → 투영 헤드(64 → 64 → 64, ELU, 새 파라미터, 같은 optimizer). 표본 B(풀 U에서 m = 1,024)에 대해 뷰 간·뷰 내 음성 포함 InfoNCE, 온도 0.5, 양방향 평균.
- λ = 0이면 위 코드는 실행되지 않는다.

### 실행 (288 run)
- 설정 16개: `base`(λ = 0) + 변형 5개 {`kl_h0`, `kl_h1`, `kl_h2`, `mse_h2`, `infonce`} × λ ∈ {0.1, 1, 10}. 풀 `nb`, τ = 0.1, m = 1,024 고정.
- × 3 데이터셋 × {1, 5}-shot × seed {0, 1, 2}. `results/T09/<cfg>/<ds>_5w<k>s/seed<s>`. `tools/run_t09.py`(`run_t07.py` 복사).

### 분석 (`tools/analyze_t09.py`)
- **표 1** 전체 격자(T07 표 1과 같은 열, `pres_loss_mean` 포함).
- **표 2** 변형별 선택(λ) 결과: 고정 test 정확도, 짝지은 차 vs `base`, vs `kl_h2`(선택), vs F(base).
- **표 3** 표현 진단: 변형별 선택 모델의 `emb_best.npy` 코사인 프로토타입 고정 test 정확도 + Â¹X 기준.
- **판정**(평균 > 0 이고 > 2·SE인 (데이터셋, shot) 수 / 6, 모두 선택 모델끼리):
  - L1 = `kl_h2` − `infonce`, L2 = `kl_h2` − `kl_h0`, L3 = `kl_h2` − `mse_h2`, L4 = `infonce` − `base`.

### 사전 등록 (수정 금지, 2026-10-06 작성)
- **P58.** L1 ≥ 4/6. **P59.** L2 ≥ 3/6. **P60.** L3 ≥ 2/6. **P61.** L4 ≥ 3/6.

### 게이트
공통 Ga–Gd + `kl_h2` λ = 1의 교사가 T07 교사와 최대 절대 차 ≤ 1e-6. `infonce` run에서 `fork_rng` 사용을 보고서에 파일·줄로 명시.

## T11 — Rehearse(가짜 클래스 에피소드) 2×2 (보고 `reports/T11_rehearse_2x2.md`, 요약 `reports/T11_summary.md`, 태그 `t11`)

### 목표
보존(P)이 있을 때 가짜 클래스 에피소드(R)가 추가 이득을 주는지 2×2로 가른다.

### 코드
- `--reh_p` (float, 기본 0.0): 0이면 원본과 같다.
- `--reh_beta` (float, 기본 1.0).
- **가짜 클래스 생성(학습 전 1회, `reh_p > 0`일 때만)**: 풀 U(`nb`)의 h̄(행 정규화 Â²X)에 sklearn `KMeans`(입력은 행 정규화 h̄, `n_clusters` = ⌊|U| / n_med⌋, n_med = base 클래스 크기 중앙값, `n_init` = 3, `random_state` = 11000 + seed). 크기 < K + Q(Q = 5)인 클러스터 제거, 나머지를 그대로 가짜 클래스로 쓴다. 남은 수가 5 미만이면 run을 실패로 기록.
- **학습 step**: 원본 base 에피소드 step은 그대로 수행한다(전역 난수 소비 순서 불변). 전용 `random.Random(12000 + seed)`로 확률 `reh_p`에 따라 같은 step에 가짜 에피소드 손실을 **더한다**: 가짜 클래스 5개 무작위 선택, 클래스마다 support K + query 5 비복원 추출, **같은 step의 전체 노드 GCN 출력을 재사용**해 EGNN·프로토타입 손실 계산. step 손실 = 원본 + λ·L_pres + 1[u]·β·L_TEG(가짜).
- 가짜 에피소드의 EGNN forward 안에 전역 난수 호출이 있으면 구현하지 말고 이 단계를 실패로 기록한 뒤 §5로 넘어간다.
- 가짜 클래스 수, 클러스터 크기 분포를 `run.json`에 기록.

### 실행 (72 run)
- 설정 4개: `base`, `P`(kl_h2 λ = 1, nb), `R`(reh_p = 0.5, β = 1), `P+R`. 3 데이터셋 × {1, 5}-shot × seed 0–2. `results/T11/...`. λ는 선택하지 않고 1로 고정.

### 분석 (`tools/analyze_t11.py`)
- **표 1** 4개 설정의 고정 test 정확도, F(cfg).
- **표 2** 짝지은 차: R − base, P − base, (P+R) − P, 상호작용 = [(P+R) − P] − [R − base].
- **표 3** 가짜 클래스 통계: 수, 크기 중앙값, 가짜 클래스와 실제 test 클래스의 정합도(가짜 클래스별 다수 실제 클래스 비율의 평균, 지표 전용).
- **판정**: R1 = (P+R) − P가 평균 > 0 이고 > 2·SE인 (데이터셋, shot) 수 / 6. R2 = R − base 같은 기준.

### 사전 등록 (수정 금지)
- **P65.** R1 ≤ 2/6. **P66.** R2 ≥ 3/6.

### 게이트
공통 Ga–Gd. 같은 seed의 가짜 클래스가 `R`과 `P+R`에서 완전히 같다.
