# T19b — E2: 레이블 없는 센서의 타당성 (학습 없음, 분석 전용)

2026-10-11 · 작성: 채팅 Claude · 모드: 채팅 지시문을 따른다 · 브랜치 `m1_sensor_check` · 태그 `t19b` · 선행: `t19a`(게이트 전부 통과)

## 0. 목적과 검증 가능한 주장

**배경.** M1 스토리의 첫 고리는 "지도 쪽이 놓치거나 지우는 영역을 레이블 없이 감지하는 센서"다. 후보 하나를 재 본다. 노드마다, 학습 임베딩의 kNN 집합이 학습 없는 기준 관점(ÂX)의 kNN 집합에서 얼마나 벗어났는지를 잰다.

장난감 실험(E4)에서 두 가지를 얻었다.
- 이 점수는 k가 작으면 잡음이 크다(k = 10에서 AUROC 0.60, k = 50에서 0.79).
- 학습 전 값과 비교해야 데이터 고유 성질과 학습 효과를 구분할 수 있다.

그래서 k를 넓게 보고, 학습 없는 대조군(rand1)을 학습 전 값의 대용으로 둔다.

**주장.** 4절의 표와 5절의 판정값, 6절의 사전 등록 대조를 산출한다. 해석은 하지 않는다. 레이블은 평가 지표에만 쓴다.

## 1. 착수

- T19a의 게이트가 모두 통과했고 태그 `t19a`가 있는지 확인한다. 아니면 시작하지 않는다.
- 코드는 `tools/analyze_t19.py`에 추가한다. T19a의 kNN 함수를 재사용한다. 코드 작성 전 멈춤 규칙은 T19a와 같다.

## 2. 입력

T19a 2절과 같다: X, ÂX, Â²X, rand1(seed 0–4), 원본(T14 `base`), 대조(T14 `uni`). 단위는 3 데이터셋 × {1, 5}-shot × seed 0–4다.

## 3. 측정

**이웃은 전체 노드 N개에서 찾는다(그룹을 모르는 센서).** 행 L2 정규화 후 코사인을 쓰고, 자기 자신은 뺀다.

| 기호 | 정의 | 레이블 사용 |
|---|---|---|
| `dep_k(i; Z, R)` | 1 − \|N_Z(i) ∩ N_R(i)\| / \|N_Z(i) ∪ N_R(i)\|. N은 top-k 이웃 집합이다. Z = 평가 대상 임베딩, R = 기준 관점. **센서 점수**이며 클수록 Z가 R에서 벗어났다는 뜻이다 | 없음 |
| `pur_i(V)` | 노드 i의 전체 노드 top-10 이웃 중 같은 레이블 비율(T19a `pur_all`의 노드별 값) | 평가만 |
| `dp(i; Z, R)` | pur_i(R) − pur_i(Z). 노드 i가 R 대비 Z에서 잃은 순도 | 평가만 |

- **k ∈ {10, 20, 50, 100}.**
- **Z ∈ {원본, 대조, rand1}.**
- **R ∈ {ÂX(주: 인코더와 hop을 맞춘 기준), Â²X(D 관점, 한 hop 더), X(0-hop, 기록만)}.**
- 학습 미사용 노드 U = valid ∪ test 그룹 노드. base 노드 B.

run마다 아래를 구한다.

| 기호 | 정의 | 뜻 |
|---|---|---|
| ρ_k | U 안에서 Spearman(dep_k, dp) | **주 지표.** base/비base 구분은 학습 때 이미 알려져 있다. 그래서 센서의 쓸모는 U 안에서 "어디가 지워졌는가"를 가리키는 데 있다 |
| AUC_drop_k | U 안에서 dep_k로 {dp > 0}(순도를 잃은 노드)와 {dp ≤ 0}를 가르는 AUROC | 주 지표의 이진판 |
| AUC_grp_k | 전체 노드에서 dep_k로 U와 B를 가르는 AUROC | 학습이 만든 벗어남이 학습 미사용 영역에 몰리는가. rand1 값이 "학습 없는" 기준이다 |
| mean_dep_k(g) | 그룹 g(base, valid, test)의 dep_k 평균 | 기록 |

- **무작위성 없음**(rand1의 오프셋 2000 제외).
- 중간 산출물은 저장하지 않는다. 다만 Amazon_clothing 1-shot seed 0, Z = 원본, R = ÂX에 대해서만 노드별 (dep_10, dep_50, dp, 그룹)을 `results/T19b/example_nodes.npz`로 저장한다. 그림 1에 쓴다.
