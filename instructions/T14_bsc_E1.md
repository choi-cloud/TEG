## 0. 목표와 이름
대조 학습(InfoNCE)은 지금 풀 U(`nb`)에서 1,024개 노드를 **균일하게** 뽑아 배치를 만든다. 이 배치를 어떻게 만드느냐**만** 바꾼다. 확인할 것은 두 가지다.
1. 지도 모듈(TEG)이 **같은 base 클래스로 보는 노드끼리** 모은 배치(BSC)가 균일 배치보다 나은가.
2. 단순히 임베딩상 가까운 노드끼리 모은 배치(표준 BatchSampler)보다 나은가.

손실 식, 증강, 투영 헤드, λ, 추론은 모두 그대로다.

| 별칭 | `--neg_sampler` | 배치 구성 |
|---|---|---|
| **원본** | — (λ = 0) | 보조 손실 없음 |
| **대조** | `uniform`(기본) | U에서 균일 추출. 현재 코드와 같다 |
| **근접** | `emb_rwr` | U 전체의 임베딩 k-최근접 그래프 위 RWR (표준 BatchSampler) |
| **BSC** | `bsc_rwr` | **같은 base 프로토타입에 배정된 노드끼리만** 이은 k-최근접 그래프 위 RWR |
| **BSC+심판** | `bsc_rwr` + `--referee_k 10` | BSC 배치에서 Â²X 기준으로도 가까운 쌍을 음성에서 제외 |

## 1. 코드
새 파일 `bsc_sampler.py`를 만들고, `model.py`·`argument.py`는 최소한으로 바꾼다. 신규 플래그는 모두 `config2string` 제외 목록에 넣는다.

### 1.1 플래그 (기본값 = 현재 동작)
- `--neg_sampler` {`uniform`, `emb_rwr`, `bsc_rwr`}, 기본 `uniform`.
- `--rwr_alpha` (float, 기본 0.1): RWR 재시작 확률.
- `--rwr_k` (int, 기본 10): 근접 그래프의 이웃 수.
- `--referee_k` (int, 기본 0): 0이면 심판을 끈다.
- 배치 크기 M은 기존 `--pres_m`(1,024)을 그대로 쓴다.
- `--pres_loss infonce`가 아닐 때 위 플래그는 무시한다.

### 1.2 근접 그래프 (에폭마다 다시 만든다)
- **시점**: 학습 에폭 1–10 각각의 첫 step 직전. 에폭 0은 업데이트가 없으므로 만들지 않는다.
- **표현**: 현재 모델의 전체 노드 GCN 출력에 LayerNorm을 적용한 z(EGNN 좌표 입력, 보존 손실의 학생과 같은 것).
  - eval 모드, `no_grad`, `torch.random.fork_rng(devices=[현재 device])` 안에서 계산한다. 계산이 끝나면 train 모드로 되돌린다.
- **base 프로토타입**(`bsc_rwr`만): base 클래스(`class_list_train`에서 valid 클래스를 뺀 것)마다 그 클래스의 전체 레이블 노드의 z 평균을 내고 L2 정규화한다.
  - 학습 데이터의 base 레이블만 쓴다. valid·test 레이블은 쓰지 않는다.
- **배정**(`bsc_rwr`만): U의 노드 u마다 argmax_c cos(z_u, p_c)로 그룹을 정한다.
- **간선**: 노드마다 코사인 상위 `rwr_k`개 이웃(자기 자신 제외)을 잇고 무향화한다.
  - `emb_rwr`: 이웃을 U 전체에서 찾는다.
  - `bsc_rwr`: 이웃을 **같은 그룹 안에서만** 찾는다. 그룹 크기가 `rwr_k` + 1보다 작으면 가능한 만큼만 잇는다.
  - 유사도는 GPU에서 행 블록 단위로 계산해 메모리를 제한한다.

### 1.3 RWR 배치 (step마다)
- 전용 생성기 `np.random.default_rng(14000 + seed)`를 쓴다(§8 등록부의 BSC 예약 범위).
- 절차:
  1. U에서 시작 노드 s를 균일하게 뽑는다.
  2. 현재 노드에서 확률 α로 s에 돌아가고, 아니면 이웃 중 하나로 균일하게 이동한다.
  3. 방문한 노드를 중복 없이 배치에 넣는다.
- 이웃이 없거나 연속 `10·M` 걸음 동안 새 노드가 없으면, 배치에 없는 U 노드 중 새 시작 노드를 균일하게 뽑는다("점프").
- M개를 채우면 멈춘다.
- 이렇게 만든 배치가 기존 균일 표본 자리에 그대로 들어간다. 이후 증강, 양성, 음성, 온도 0.5, 양방향 평균은 변경 없다.
- `uniform`일 때는 기존 코드 경로와 생성기(7000 + seed)를 **한 줄도 바꾸지 않고** 쓴다.

### 1.4 심판 (`referee_k` > 0)
- **학습 전 1회**: U 안에서 행 정규화 Â²X의 코사인 상위 `referee_k` 이웃 집합 R(i)를 구한다.
- **InfoNCE 계산 시**: j ∈ R(i)이거나 i ∈ R(j)인 쌍 (i, j), i ≠ j는 뷰 간·뷰 내 음성 logit을 −∞로 둔다. 양성(같은 노드의 다른 뷰)은 건드리지 않는다.

### 1.5 진단 기록 (지표 전용, `run.json`의 에폭별 로그)
레이블은 아래 지표 계산에만 쓰며, 손실과 배치 구성에는 쓰지 않는다. 에폭마다 그 에폭 배치들의 평균을 기록한다.
- `fn_rate`: 배치 안 서로 다른 노드 쌍 가운데 음성으로 실제 사용된 쌍(심판이 가린 쌍 제외) 중, 실제 레이블이 같은 비율.
- `same_proto_rate`: 배치 안 쌍 중 같은 base 프로토타입에 배정된 비율. 배정은 1.2와 같은 방식으로 하며, 모든 sampler에서 기록한다(`uniform`·`emb_rwr`도 같은 방식으로 배정만 계산).
- `masked_frac`: 심판이 가린 음성 쌍의 비율.
- `jumps`: 배치당 점프 수.
- 그래프 통계: 그룹 수, 그룹 크기 중앙값, 이웃 없는 노드 수.
